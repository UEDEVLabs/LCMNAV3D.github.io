Tutorial 01: Installation

Applies to LCM Nav3D 3.6.0 · Unreal Engine 5.2 to 5.8 · Updated 22 November 2026

In short: Put the plugin in YourProject/Plugins/LCMNav3D/, open the project and let it compile, enable Show Plugin Content in the Content Browser, then open the QuickStart level and press Play. If its displays pass, your install is good. The demo levels are a free download from the LCM Nav3D menu.

Time: ~10 minutes (plus one compile).

Before you start

Requirement Detail
Unreal Engine 5.2 to 5.8
Platform Windows 64-bit or Linux
Project type C++ project for a manual install (see below)
Compiler Visual Studio 2022 with the Game development with C++ workload (Windows)

The plugin comes as source code, so it has to be compiled once. How that happens depends on how you install it.

Method A: Installed from Fab / Epic Games Launcher

This is the easiest way, and it works with Blueprint-only projects.

  1. Install the plugin from the Launcher's Library → Fab Library section. It lands in <Engine>/Plugins/Marketplace/LCMNav3D/ and is already compiled for that engine version.
  2. Open your project.
  3. Edit → Plugins, search "LCM Nav3D", tick Enabled if it isn't already.
  4. Restart the editor when prompted.

Skip to Verify the install.

Method B: Manual install into your project

Use this when you have the plugin as a folder (for example from a direct purchase or a version you re-targeted yourself).

  1. Close the editor.

  2. Copy the LCMNav3D folder into your project so the layout is: 

    YourProject/
  YourProject.uproject
  Plugins/
    LCMNav3D/
      LCMNav3D.uplugin
      Source/
      Content/
      Config/
      Shaders/

Create the Plugins folder if your project doesn't have one. The folder must be named exactly LCMNav3D, because the content mount /LCMNav3D/ depends on it.

  1. If your project is Blueprint-only, convert it to C++ first. A Blueprint-only project has no build pipeline and cannot compile a source plugin. The easiest conversion: Tools → New C++ Class → None → Create Class. The editor generates a Source/ folder and restarts. You never have to write any C++ afterwards.

  2. Right-click YourProject.uproject → Generate Visual Studio project files.

  3. Open the generated .sln and build Development Editor | Win64, or open the .uproject and click Yes when the editor offers to rebuild.

  4. The plugin is EnabledByDefault, so it turns itself on. Confirm under Edit → Plugins.

Verify the install

Do these in order. Each one catches a different kind of failure.

1. The plugin loaded

Edit → Plugins → AI Navigation category. You should see LCM Nav3D, enabled, version 3.6.0.

2. Get the demo levels (optional)

The demo levels, their art and the demo menu are a free download, LCM Nav3D Samples (about 0.9 GB to download, 1.3 GB installed). Your game does not need them.

  • To install them: LCM Nav3D toolbar menu → Get the Demo Levels (free)... (or Demo Levels (free) on the Welcome screen) → Download and Install. The window shows the progress; you can pause, resume or cancel, and an interrupted download resumes where it stopped. Every file is checked before it is installed, into YourProject/Plugins/LCMNav3DSamples. When it finishes, Open the Demo Menu.
  • Updates and removal: the same window offers a newer version when one is published, and Remove Samples. Both finish when the editor next starts. Nothing in LCM Nav3D refers to the samples.

3. You can see the demo content

Plugin content is hidden by default in the Content Browser:

Content Browser → Settings (the gear icon) → tick "Show Plugin Content".

An LCM Nav3D Content folder appears in the tree (and LCM Nav3D Samples Content once the demo levels are installed). Without this you won't find the QuickStart level or any demo map. If it looks like the plugin didn't install, check this setting first.

4. A level runs

Open LCM Nav3D Content → QuickStart → QuickStart (or QuickStart Level on the Welcome screen) and press Play. Walk up to a display to start it. One agent flies over and under obstacles, a large and a small agent take different routes, a patrol loops, and a Blueprint queries paths. Each display shows PASSED when its check succeeds. Press O to see the planned routes.

With the demo levels installed, open LCM Nav3D Samples Content → Demo → MainMenu, press Play and pick a level.

Demo → MainMenu is a gallery of every demo in the plugin, if you would rather browse than open maps by name.

If that works, your install is correct and you can move on to Tutorial 02: Core Concepts.

The engine plugins it turns on

LCMNav3D.uplugin lists these as dependencies, so the engine turns them on for you. You don't need to change anything, but you should know they are enabled:

Plugin Why it's needed
StateTree, GameplayStateTree The StateTree task/condition/evaluator set
MassEntity, MassGameplay, MassAI The Mass crowd layer
SmartObjects Smart Object behaviour definitions
DataValidation In-editor validation of illegal Mass trait combinations

If the plugin fails to load with GetLastError 126, one of the Mass plugins got disabled. MassGameplay in particular is required at runtime. Re-enable it and restart.

Common install problems

"The following modules are missing or built with a different engine version: LCMNav3D" The plugin hasn't been compiled for your engine build. Click Yes to rebuild. If the rebuild fails, you are on a Blueprint-only project, so go back to Method B step 3.

I can't find the demo maps. They are a free download: LCM Nav3D menu → Get the Demo Levels (free)... (verification step 2). Then enable Show Plugin Content (step 3).

The plugin is missing from the Plugins window entirely. The folder is in the wrong place or misnamed. It must be YourProject/Plugins/LCMNav3D/LCMNav3D.uplugin. Check you didn't end up with a doubled folder like Plugins/LCMNav3D/LCMNav3D/.

Compile errors mentioning StateTree or Mass types. An engine plugin dependency was disabled. Re-enable the table above and regenerate project files.

More in Troubleshooting.

Other engine versions

There is a separate copy of the plugin for each supported engine version, 5.2 through 5.8, and each one is built and tested on that engine.

Install the copy that matches your project instead of re-targeting this one. Engine APIs change between versions, and each copy already has the changes for its version.
